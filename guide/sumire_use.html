Sumire+ の使い方

携帯（スマホ）用

0. 開き方とメニュー

ホーム画面の「Sumire+」のアイコンを押して開きます。
（ブラウザからではなく、アイコンから開いてください。いちばん早く開きます）

開くのに 8〜9秒かかることがあります。「読み込み中…」の間はお待ちください。

6桁のパスワードをまた聞かれても、故障ではありません。
開き方（Safari・ホーム画面のアイコン・LINE ワークスの中）ごとに、 最初の1回だけ聞かれます。2回目からは聞かれません。

開くと、ボタンが4つ並んでいます。

📸 撮影　… 保険証・指示書・処置の写真などを送信
📝 変更報告　… 訪問予定やケアマネの変更を報告
📅 予定表　… 毎日の訪問予定表を見る
📢 お知らせ　… 事務所からの連絡の確認・登録
どの画面からでも、いちばん下の ［← メニューに戻る］ で最初に戻れます。

1. 📸 撮影 — 書類や写真の送信

手順

  1. メニューの ［📸 撮影］ を押す
  2. ① 撮影者　… 自分の名前が最初から入っています（変更できません）
  3. ② 利用者　… 🔍 名前で検索 に名前を入力すると候補が表示されます。押して選択
    未登録の方は「🆕 新規利用者氏名」に手入力
  4. ③ 何を撮影しますか　… 下の9つから選択
  5. ［📷 カメラを起動］ で撮影。撮影済みの写真なら［🖼️ 写真ライブラリから選択］
  6. 確認の画面が出ます。写真をタップすると大きく見えます（もう一度タップで閉じる）
    保険証のときは「🤖 AI 判定中…」と出て、種類が自動で入ります
  7. 足りなければ ［📷 もう1枚］、再撮影する場合は ［↺ 再撮影］。 入れ間違えたら ［← 情報修正に戻る］
  8. ［📤 送信する］を押す。「✓ 送信完了」が出たら終わりです

③ で選択できる9つ

保険証自己負担上限管理表処置写真
家・駐車場お薬手帳検査データ
サマリー利用者写真その他

保険証の種類は、AI が自動で決めます

種類を自分で選択する必要はありません。 撮影すると 「🤖 AI 判定中…」 と出て、そのあと 「🤖 AI 判定結果（修正可）」 として 種類がすでに入った状態で出ます。欄には 「🤖自動」 と付いています。

合っていれば、そのまま ［📤 送信する］ を押してください。

異なる場合は、その場で押して修正できます。（修正した内容が送信されます）

参考：AI が自動入力する種類は、介護保険／医療保険／後期高齢／公費／負担割合証 の5つです。 医療保険と公費は、さらに細かい種類まで入ります。いずれも選択する必要はありません。

送信すると、LINE WORKS の「個人情報共有」グループに自動で通知が届きます。 そのあと、あらためて連絡しなくてかまいません。

通知には、いちばん下に「📦 Box：」のリンクが付きます。 押すと、その写真が開きます（複数枚送信した場合は、1枚ずつリンクが並びます）。

写真そのものは LINE WORKS に貼られません。付くのはリンクだけです。

2. 📝 変更報告 — 変更内容の報告

まず、5つの種類から選択します

📅 訪問予定変更訪問日時の変更・休み・追加
→ さらに3つから選択します
📋 訪問プラン変更入院・終了・休止・再開・退院
→ さらに4つから選択します
🆕 新規利用者追加新しく始まる方
👤 ケアマネ変更担当ケアマネの変更
🏥 かかりつけ医変更主治医・医療機関の変更

📅 と 📋 は、もう一段階 選択します

📅 訪問予定変更 🔄 日時変更／訪問休み（振替有）　・　🚫 訪問休み（振替無し）　・　➕ 訪問追加
📋 訪問プラン変更 📋 プラン変更（回数・曜日・時間など）　・　🛑 訪問終了・休止　・　🏥 入院　・　▶ 訪問再開・退院

手順

  1. メニューの ［📝 変更報告］ を押す
  2. 5つから、報告したい種類を押す（📅 と 📋 は、その後もう一段階 選択）
  3. 画面の ① ② ③ … の順に、＊ の付いた欄を埋める
    欄の内容は、種類ごとに異なります。「任意」と付いている欄は、把握している範囲でかまいません
  4. 緑の点線が付いた欄は、自動で入ったものです（入力不要です）
  5. 一番下で、通知するグループを選択
    業務グループ　／　非常勤グループ　／　両方
    「両方」を選択すると、業務グループと非常勤グループへ同時に送信できます
  6. 確認画面で内容を確認し、［送信する］
自分の名前（報告者）は、たいてい ① に最初から入っています。
ただし 🔄 日時変更 の画面だけは 報告者の欄がありません。 かわりに ② 訪問担当者 が報告者を兼ねます。
入れ忘れた欄があると、その場所まで自動で戻ります。赤くなっている欄を埋めてください。

入力不要の欄（自動で入力されます）

緑の点線が付いている欄は、すでに自動で入っています。 合っていれば、そのままでかまいません。異なる場合は、その場で修正できます。

・報告者　…　自分の名前
・事業所　…　選択したケアマネから自動で入ります
・医療機関　…　選択した先生から自動で入ります
・終了時刻　…　開始時刻から自動で入ります
・初回看護の時間　…　30分と決まっているため、開始時刻を選択すると自動で入力されます

送信すると、選択したグループに自動で通知が届きます。

変更報告の通知は、報告者・利用者・変更日・変更内容が すべて文字で記載されます。 リンクは付きません（その文面だけで内容を確認できます）

3. 📅 予定表 — 毎日の訪問予定を見る

予定表は、夕方に自動で入ります。 誰かが送信したり、貼り付けたりする必要はありません。

17時15分ごろから17時45分ごろのあいだに、次の日の分が自動で入ります。 だから、夕方には 翌日の予定を確認できます。

  1. メニューの ［📅 予定表］ を押す
  2. 夕方 17時30分より前は「今日」、17時30分以降は「あす」を先に表示します
  3. ［← 前の日］［次の日 →］ で日付を切り替えられます。［今日にもどる］で戻れます
  4. 指2本で広げると大きくなります（＋ ・ − ・もとの大きさ のボタンもあります）
  5. 閉じるときは黒いところを押す
金曜は、土曜とその次の月曜の2枚が入ります。
予定表は見るだけです。ここから変更はできません。変更は ［📝 変更報告］ から。

4. 📢 お知らせ — 事務所からの連絡

見る

  1. メニューの ［📢 お知らせ］ を押すと、新しい順に並びます
    1つずつ 見出し・日付と送信者・ボタンが出ます
  2. 赤い NEW が付いているのは3日以内のものです
  3. ［🖼️ 写真を見る］を押すと、写真が大きく開きます
  4. たくさんあるときは 🔍 見出しで検索 に言葉を入力して絞り込めます

入れる

  1. ［＋ 新規登録］ を押す
  2. ① 送信者　… 自分の名前が入っています
  3. ② 見出し　… 1行・100字まで（例：事務所に用紙を置いています）
  4. ［📷 カメラを起動］ か ［🖼️ 写真ライブラリから選択］ で写真を1枚
  5. ［✓ 確認して送信］

登録すると、LINE WORKS の「業務」と「非常勤」の両方に通知が送信されます。
中身は 「📢 お知らせ」＋見出し＋リンク の3行です。 リンクを押すと Sumire+ が開き、該当のお知らせが表示されます。

写真そのものは貼られません（付くのはリンクだけ）。

PDF を付けられるのはパソコンからだけです。携帯からは写真1枚です。

削除

一覧の各お知らせの下にある ［🗑 このお知らせを削除］ を押します。誰でも削除できます。 間違えて登録したときは、その場で削除してかまいません。

削除したものは30日はゴミ箱に残るので、慌てなくて大丈夫です。

古いお知らせが自動で削除されることはありません。不要になったら削除してください。

お願い

  1. 利用者さんの写真や書類は、LINE WORKS に貼らないでください。必ず Sumire+ から
  2. 6桁のパスワードは、人に教えないでください
