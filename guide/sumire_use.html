Sumire+ の使い方

携帯（スマホ）用

0. 開き方とメニュー

ホーム画面の「Sumire+」のアイコンを押して開きます。
（ブラウザからではなく、アイコンから開いてください。いちばん早く開きます）

開くのに 8〜9秒かかることがあります。「読み込み中…」のまま少し待ってください。

開くと、ボタンが4つ並んでいます。

📸 撮影　… 保険証・指示書・処置の写真などを送る
📝 変更報告　… 訪問予定やケアマネの変更を知らせる
📅 予定表　… 毎日の訪問予定表を見る
📢 お知らせ　… 事務所からの連絡を見る・入れる
どの画面からでも、いちばん下の ［← メニューに戻る］ で最初に戻れます。

1. 📸 撮影 — 書類や写真を送る

手順

  1. メニューの ［📸 撮影］ を押す
  2. ① 撮影者　… 自分の名前が最初から入っています（変えられません）
  3. ② 利用者　… 🔍 名前で検索 に名前を打つと候補が出ます。押して選ぶ
    まだ登録のない方は「🆕 新規利用者氏名」に手で入れる
  4. ③ 何を撮影しますか　… 下の9つから選ぶ
    「保険証」を選ぶと、さらに種類を選ぶ欄が出ます（次の表）
  5. ［📷 カメラを起動］ で撮る。すでに撮ってある写真なら［🖼️ 写真ライブラリから選ぶ］
  6. 確認の画面が出ます。写真をタップすると大きく見えます（もう一度タップで閉じる）
  7. 足りなければ ［📷 もう1枚］、撮り直すなら ［↺ 撮り直す］。 入れ間違えたら ［← 情報修正に戻る］
  8. ［📤 送信する］を押す。「✓ 送信完了」が出たら終わりです

③ で選べる9つ

保険証自己負担上限管理表処置写真
家・駐車場お薬手帳検査データ
サマリー利用者写真その他
迷ったら「その他」で送ってかまいません。事務所で見て振り分けます。

「保険証」を選んだときに出る欄

まず、この5つから選びます。

介護保険　／　医療保険　／　後期高齢　／　公費　／　負担割合証

「医療保険」と「公費」は、さらに細かく選びます。

医療保険社会保険／国民健康保険／マイナ保険証／資格確認書／生活保護受給者
公費こども医療費助成／重度障がい者医療費助成／特定医療費受給者証／自立支援受給者証
券面に書いてあるとおりに選んでください。分からないときは 「その他」で送って、あとで事務所に一言ください。

送ると、LINE WORKS の「個人情報共有」グループに自動で知らせが届きます。 そのあと、あらためて連絡しなくてかまいません。

知らせに写真は付きません（写真そのものは LINE WORKS に流れません）。

2. 📝 変更報告 — 変わったことを知らせる

5つの種類から選びます

📅 訪問予定変更訪問の日時を変える・休む・足す
📋 訪問プラン変更入院・終了・休止・再開・退院
🆕 新規利用者追加新しく始まる方
👤 ケアマネ変更担当のケアマネが変わった
🏥 かかりつけ医変更主治医・医療機関が変わった

手順

  1. メニューの ［📝 変更報告］ を押す
  2. 上の5つから、報告したい種類を押す
  3. ① 報告者　… 自分の名前が最初から入っています
  4. ② 利用者　… 名前で検索して選ぶ
  5. あとは ＊ の付いた欄を埋める（＊が付いていない欄は、分かる範囲で）
  6. どのグループに知らせるかを選ぶ　…　業務グループ／非常勤グループ
  7. 確認の画面で中身を見て、［送信する］
入れ忘れた欄があると、その場所まで自動で戻ります。赤くなっている欄を埋めてください。

3. 📅 予定表 — 毎日の訪問予定を見る

  1. メニューの ［📅 予定表］ を押す
  2. 夕方 17時30分より前は「今日」、17時30分を過ぎると「あす」が最初に出ます
  3. ほかの日も選べます。［今日にもどる］で戻れます
  4. 指2本で広げると大きくなります（＋ ・ − ・もとの大きさ のボタンもあります）
  5. 閉じるときは黒いところを押す
金曜は、土曜とその次の月曜の2枚が入ります。
予定表は見るだけです。ここから変更はできません。変更は ［📝 変更報告］ から。

4. 📢 お知らせ — 事務所からの連絡

見る

  1. メニューの ［📢 お知らせ］ を押すと、新しい順に並びます
  2. 赤い NEW が付いているのは3日以内のものです
  3. 見出しを押すと写真が大きく開きます
  4. たくさんあるときは 🔍 見出しでさがす に言葉を入れて絞れます

入れる

  1. ［＋ 新しく入れる］ を押す
  2. ① 送信者　… 自分の名前が入っています
  3. ② 見出し　… 1行・100字まで（例：事務所に用紙を置いています）
  4. ［📷 カメラを起動］ か ［🖼️ 写真ライブラリから選ぶ］ で写真を1枚
  5. ［✓ 確認して送信］

入れると、LINE WORKS の「業務」と「非常勤」の両方に知らせが流れます（2行だけ・写真は付きません）。

PDF を付けられるのはパソコンからだけです。携帯からは写真1枚です。

消す

一覧のそれぞれの下にある ［🗑 このお知らせを消す］ を押します。誰でも消せます。 間違えて入れたときは、その場で消してかまいません。

消したものは30日はゴミ箱に残るので、慌てなくて大丈夫です。

古いお知らせが自動で消えることはありません。要らなくなったら消してください。

5. 困ったとき

「6桁のパスワード」をまた聞かれた
→ こわれていません。開き方（Safari・アイコン・LINE ワークスの中）ごとに、最初の1回だけ聞かれます。

名前の一覧に自分がいない／利用者さんが出てこない　→　谷川さんへ

送信でつまずく・画面が出ない　→　谷川さんへ

お願い

  1. 利用者さんの写真や書類は、LINE WORKS に貼らないでください。必ず Sumire+ から
  2. 6桁のパスワードは、人に教えないでください
