Sumire+ の使い方

携帯（スマホ）用

0. 開き方とメニュー

ホーム画面の「Sumire+」のアイコンを押して開きます。
（ブラウザからではなく、アイコンから開いてください。いちばん早く開きます）

開くのに 8〜9秒かかることがあります。「読み込み中…」のまま少し待ってください。

開くと、ボタンが4つ並んでいます。

📸 撮影　… 保険証・指示書・処置の写真などを送る
📝 変更報告　… 訪問予定やケアマネの変更を知らせる
📅 予定表　… 毎日の訪問予定表を見る
📢 お知らせ　… 事務所からの連絡を見る・入れる
どの画面からでも、いちばん下の ［← メニューに戻る］ で最初に戻れます。

1. 📸 撮影 — 書類や写真を送る

手順

  1. メニューの ［📸 撮影］ を押す
  2. ① 撮影者　… 自分の名前が最初から入っています（変えられません）
  3. ② 利用者　… 🔍 名前で検索 に名前を打つと候補が出ます。押して選ぶ
    まだ登録のない方は「🆕 新規利用者氏名」に手で入れる
  4. ③ 何を撮影しますか　… 下の9つから選ぶ
  5. ［📷 カメラを起動］ で撮る。すでに撮ってある写真なら［🖼️ 写真ライブラリから選ぶ］
  6. 確認の画面が出ます。写真をタップすると大きく見えます（もう一度タップで閉じる）
    保険証のときは「🤖 AI 判定中…」と出て、種類が自動で入ります
  7. 足りなければ ［📷 もう1枚］、撮り直すなら ［↺ 撮り直す］。 入れ間違えたら ［← 情報修正に戻る］
  8. ［📤 送信する］を押す。「✓ 送信完了」が出たら終わりです

③ で選べる9つ

保険証自己負担上限管理表処置写真
家・駐車場お薬手帳検査データ
サマリー利用者写真その他

保険証の種類は、AI が自動で決めます

種類を自分で選ぶ必要はありません。 撮ると 「🤖 AI 判定中…」 と出て、そのあと 「🤖 AI 判定結果（修正可）」 として 種類がすでに入った状態で出ます。欄には 「🤖自動」 と付いています。

合っていれば、そのまま ［📤 送信する］ を押してください。

もし違っていたら、その場で押して直せます。（直したものが送られます）

参考＝AI が入れる種類は、介護保険／医療保険／後期高齢／公費／負担割合証 の5つです。 医療保険と公費は、さらに細かい種類まで入ります。どれも自分で選ぶ必要はありません。

送ると、LINE WORKS の「個人情報共有」グループに自動で知らせが届きます。 そのあと、あらためて連絡しなくてかまいません。

知らせには、いちばん下に「📦 Box：」のリンクが付きます。 押すと、その写真が開きます（何枚も送ったときは、1枚ずつリンクが並びます）。

写真そのものは LINE WORKS に貼られません。付くのはリンクだけです。

2. 📝 変更報告 — 変わったことを知らせる

まず、5つの種類から選びます

📅 訪問予定変更訪問の日時を変える・休む・足す
→ さらに3つから選びます
📋 訪問プラン変更入院・終了・休止・再開・退院
→ さらに4つから選びます
🆕 新規利用者追加新しく始まる方
👤 ケアマネ変更担当のケアマネが変わった
🏥 かかりつけ医変更主治医・医療機関が変わった

📅 と 📋 は、もう一段 選びます

📅 訪問予定変更 🔄 日時変更／訪問休み（振替有）　・　🚫 訪問休み（振替無し）　・　➕ 訪問追加
📋 訪問プラン変更 📋 プラン変更（回数・曜日・時間など）　・　🛑 訪問終了・休止　・　🏥 入院　・　▶ 訪問再開・退院

手順

  1. メニューの ［📝 変更報告］ を押す
  2. 5つから、報告したい種類を押す（📅 と 📋 は、そのあともう一段 選ぶ）
  3. 画面の ① ② ③ … の順に、＊ の付いた欄を埋める
    欄の中身は、種類ごとに違います。「任意」と付いている欄は、分かる範囲でかまいません
  4. 緑の点線が付いた欄は、自動で入ったものです（自分で入れなくてかまいません）
  5. いちばん下で、どのグループに知らせるかを選ぶ　…　業務グループ／非常勤グループ
  6. 確認の画面で中身を見て、［送信する］
自分の名前（報告者）は、たいてい ① に最初から入っています。
ただし 🔄 日時変更 の画面だけは 報告者の欄がありません。 かわりに ② 訪問担当者 が報告者を兼ねます。
入れ忘れた欄があると、その場所まで自動で戻ります。赤くなっている欄を埋めてください。

自分で入れなくてよい欄（自動で入ります）

緑の点線が付いている欄は、すでに自動で入っています。 合っていれば、そのままでかまいません。違っていれば、その場で直せます。

・報告者　…　自分の名前
・事業所　…　選んだケアマネから自動で入ります
・医療機関　…　選んだ先生から自動で入ります
・終了時刻　…　開始時刻から自動で入ります
・初回看護の時間　…　30分と決まっているので、開始を選ぶと自動で入ります

送ると、選んだグループに自動で知らせが届きます。

変更報告の知らせは、報告者・利用者・変更日・変わった中身が すべて文字で入ります。 リンクは付きません（その文だけで分かるようになっています）。

3. 📅 予定表 — 毎日の訪問予定を見る

  1. メニューの ［📅 予定表］ を押す
  2. 夕方 17時30分より前は「今日」、17時30分を過ぎると「あす」が最初に出ます
  3. ［← 前の日］［次の日 →］ で日を送れます。［今日にもどる］で戻れます
  4. 指2本で広げると大きくなります（＋ ・ − ・もとの大きさ のボタンもあります）
  5. 閉じるときは黒いところを押す
金曜は、土曜とその次の月曜の2枚が入ります。
予定表は見るだけです。ここから変更はできません。変更は ［📝 変更報告］ から。

4. 📢 お知らせ — 事務所からの連絡

見る

  1. メニューの ［📢 お知らせ］ を押すと、新しい順に並びます
    1つずつ 見出し・日付と送信者・ボタンが出ます
  2. 赤い NEW が付いているのは3日以内のものです
  3. ［🖼️ 写真を見る］を押すと、写真が大きく開きます
  4. たくさんあるときは 🔍 見出しでさがす に言葉を入れて絞れます

入れる

  1. ［＋ 新しく入れる］ を押す
  2. ① 送信者　… 自分の名前が入っています
  3. ② 見出し　… 1行・100字まで（例：事務所に用紙を置いています）
  4. ［📷 カメラを起動］ か ［🖼️ 写真ライブラリから選ぶ］ で写真を1枚
  5. ［✓ 確認して送信］

入れると、LINE WORKS の「業務」と「非常勤」の両方に知らせが流れます。
中身は 「📢 お知らせ」＋見出し＋リンク の3行です。 リンクを押すと Sumire+ が開いて、そのお知らせがそのまま出ます。

写真そのものは貼られません（付くのはリンクだけ）。

PDF を付けられるのはパソコンからだけです。携帯からは写真1枚です。

消す

一覧のそれぞれの下にある ［🗑 このお知らせを消す］ を押します。誰でも消せます。 間違えて入れたときは、その場で消してかまいません。

消したものは30日はゴミ箱に残るので、慌てなくて大丈夫です。

古いお知らせが自動で消えることはありません。要らなくなったら消してください。

5. 困ったとき

「6桁のパスワード」をまた聞かれた
→ こわれていません。開き方（Safari・アイコン・LINE ワークスの中）ごとに、最初の1回だけ聞かれます。

名前の一覧に自分がいない／利用者さんが出てこない　→　谷川さんへ

送信でつまずく・画面が出ない　→　谷川さんへ

お願い

  1. 利用者さんの写真や書類は、LINE WORKS に貼らないでください。必ず Sumire+ から
  2. 6桁のパスワードは、人に教えないでください
