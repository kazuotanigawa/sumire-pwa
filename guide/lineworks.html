LINE WORKS を携帯に入れる手順

※ ID とパスワードは、別に渡されたものを使ってください

ID 
パスワード 

1. アプリを入れる

  1. iPhone の方
    「App Store」を開いて、LINE WORKS を探して入れる
  2. Android の方
    「Google Play」を開いて、LINE WORKS を探して入れる

2. ログインする

  1. アプリを開いて、最初の画面の ［ログイン］ を押す
  2. ID を入れて ［ログイン］ を押す
  3. パスワード を入れて ［ログイン］ を押す
  4. 「携帯番号の認証」が出たら → ［キャンセル］を押す
  5. これでログイン完了です
打ち間違えやすい文字に気をつけてください
・数字の 1 と アルファベットの I（大文字のアイ）・i（小文字のアイ）
・数字の 0 と アルファベットの O（大文字のオー）・o（小文字のオー）

やらないでほしいこと（3つ）

  1. パスワードを自分で変えない
  2. 2段階認証を ON にしない
  3. 携帯番号の認証をしない（出たら［キャンセル］）

3. 知っておいてほしいこと

指紋や暗証番号だけでは入れません。毎回パスワードを打ちます。
→ パスワードは、なくさないように控えておいてください。

30日 開かないと、ログアウトされます。
そのときは、またパスワードを打ってください。

4. 困ったとき

「新しいパスワードを登録してください」と出たとき
→ 自分で決めずに、管理者に声をかけてください。

パスワードが違うと出るとき
→ 上の「打ち間違えやすい文字」をもう一度 確かめてください。
→ 5回 続けて間違えると、しばらく入れなくなります。 しばらく待ってから、もう一度お試しください。
